# Tipografía de la invitación

La web usa dos familias tipográficas:

- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) para nombres, títulos, lugares destacados y frases breves.
- [Manrope](https://fonts.google.com/specimen/Manrope) para texto de lectura, fechas, direcciones, controles, formularios y administración.

Los archivos WOFF2 se alojan en `public/fonts` con sus licencias OFL. Se conservan los subconjuntos latinos y cirílicos de ambas familias para el valenciano, el ucraniano y los nombres de las personas invitadas. La web no solicita tipografías a un servicio externo.
